# UX and Visual Design

Warm cream classroom background, teal primary actions, orange and yellow rewards, dark readable text. Friendly locally drawn school/teacher and avatar visuals; avoid relying only on emoji for essential meaning.

Responsive mobile-first RTL. A restrained desktop max-width preserves readable cards. Main touch controls at least 44 CSS px high, generous gaps, system Arabic-capable font stack and no remote font requests.

Clear visual hierarchy: one main action, one prompt, three vertically stacked answer cards on mobile. Feedback includes text and icon, not color alone. Focus moves to the active screen/feedback as appropriate. Status feedback uses live regions. Browser zoom remains enabled. Animation respects prefers-reduced-motion.

Language is short Egyptian Arabic, warm without shaming, gender-neutral where practical. Avoid labels such as stupid, bad child, IQ or moral score. Academic vocabulary remains correct.

Default bright theme only. No dark-mode or audio feature is necessary for this release. Local illustrations and simple CSS transitions keep transfer and maintenance small.
