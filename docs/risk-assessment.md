# Risk Assessment

| Risk | Control |
|---|---|
| Incorrect or ambiguous questions | Schema checks, mathematical review and editorial review of wording and explanations |
| Respect confused with obedience | Reciprocal respect, fair participation and requests for adult help when treatment is unfair |
| Comparison reinforces jealousy | Personal progress and cooperative scenarios; no leaderboard |
| Storage blocked or corrupt | Defensive validation, versioned data, in-memory fallback and a localized notice |
| Shared-browser profile confusion | Explicit profile selection, named active player and profile-scoped progress |
| Mobile layout or touch difficulty | Responsive RTL layout, minimum 44px design targets and viewport checks |
| Lost progress after domain change | Explain browser/origin-local storage in help and handoff |
| Hidden hosting/runtime cost | Static assets only, no Functions or external paid APIs |
| Stale release files | No service worker; revalidate release-sensitive assets |
| Unsafe user text | Render names with textContent and restrict length |

No known critical vulnerability has been found at specification time. Observed verification failures must be fixed before packaging.
