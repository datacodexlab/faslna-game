# Changelog

## 1.1.0 — 2026-10-12
- Added three lives and two hint reveals per round, with visible counters.
- A third wrong answer ends the round without granting completion or permanent rewards.
- Added a friendly game-over screen, stage restart and return to map.
- Removed automatic hints after wrong answers; requesting hints respects the round budget.
- Preserved counters and failed status on reload and migrated earlier saved rounds safely.
- Verified 22 automated tests and browser hint exhaustion, game over, reload and restart.

## 1.0.0 — 2026-10-11
- Released personalized Egyptian Arabic learning game with preset/custom player names, ages, four drawn avatars and preset/custom subject teachers.
- Added 108 academic questions and 18 social scenarios across three age bands, three subjects and three stages.
- Added guided retries, optional hints, one/two-star learning rewards, badges and replay-safe best results.
- Added independent local player progress, in-progress round restoration, defensive recovery and confirmed reset.
- Delivered responsive RTL layout, keyboard controls, feedback announcements, reduced-motion support and security headers.
- Verified 19 automated checks, all 27 rounds and observed browser flows; packaged static Cloudflare Pages and complete-source archives.

## Mobile round layout correction
The full question, all three answer buttons, hint and feedback now share one mobile screen. Answer pagination is bypassed. Result and game-over screens offer replay and another-player selection. Existing browser data is preserved. Follow-up release verification is in progress.

## 1.2.1 — 2026-10-12
- Show every answer beside the question on mobile, including hint and feedback.
- Offer replay and new-player selection after a round.
- Expand to 315 cards with randomized draws and recent-card avoidance.

A header button is available on every screen. Returning home requires confirmation and preserves browser profiles, progress and the current round. Cancelling keeps the current screen. The mobile header fits without overlaying round controls.
